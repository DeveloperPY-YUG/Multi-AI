# FAQ

**Is it free?** MULTI-AI is MIT licensed. Cloud API providers may charge for usage.

**Are chats saved?** No. Conversations are kept in memory until exit.

**Where are API keys kept?** Windows Credential Manager; they are not bundled in the source or EXE.

**Can I use it offline?** The UI is bundled locally; a running Ollama or LM Studio service can provide local responses. Cloud providers need network access.

**Is a source ZIP an EXE?** No. Download a Windows build from Releases after its workflow succeeds, or build on Windows.
